# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

Please read and follow our [Code of Conduct](CODE_OF_CONDUCT.md).

## Report an issue or suggest an improvement

Open a GitHub issue with a clear description. For bugs, include the input values,
the expected result, the actual result, and the steps needed to reproduce the
problem. Search existing issues first to avoid duplicates.

## Submit a change

1. Fork this repository and create a branch for your change.
2. Make a focused change and update the documentation if needed.
3. Run `bash -n simple-interest.sh` to check the script syntax.
4. Run `bash simple-interest.sh` with example values and check the results.
5. Commit your change, push your branch, and open a pull request explaining what
   changed and how you checked it.

By contributing, you agree that your contributions will be licensed under this
project's [Apache License 2.0](LICENSE).
